# 参数

## 说明

src 后缀支持环境变量

## 位置

```sh
config
├── sys.config.src
└── vm.args.src
```

## 分类

### sys.config.src

```erl
[
  {demo, [
    {port, ${PORT:-8080}}
  ]}
].
```

### vm.args.src

```erl
-name ${NODE_NAME:-demo@127.0.0.1}
-setcookie ${COOKIE:-123456}
```

## 测试

```sh
rebar3 as prod release
PORT=6666 _build/prod/rel/demo/bin/demo console
```
