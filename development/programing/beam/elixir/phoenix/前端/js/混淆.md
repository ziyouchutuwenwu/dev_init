# 混淆

## 说明

保护 js

## 步骤

```sh
npm install -g javascript-obfuscator
```

mix.exs

```elixir
defp aliases do
  [
    ......
    "assets.deploy": [
      # 清理之前的 digest
      "phx.digest.clean --all",

      "tailwind web_demo --minify",
      "esbuild web_demo --minify",

      # 手动指定混淆某个 js
      "cmd javascript-obfuscator priv/static/assets/js/app.js --output priv/static/assets/js/app.js --compact true --string-array true --string-array-encoding base64 --string-array-threshold 0.5",

      # 最后 digest
      "phx.digest"
    ]
  ]
end
```
