# 关键

## 说明

PHX_HOST 用于生成完整的 url, 不需写 http 或者 https

可以写局域网 ip

如果是公网，就算在 nginx 后面，也要写公网域名 xxx.com

## ssl

一般放 nginx 里面，或者嵌入式里面，不需要 ssl

prod.exs

```elixir
# 以下注掉
config :web_demo, WebDemoWeb.Endpoint,
  force_ssl: [
    rewrite_on: [:x_forwarded_proto],
    exclude: [
      # paths: ["/health"],
      hosts: ["localhost", "127.0.0.1"]
    ]
  ]
```

## http

如果是纯 http

runtime.exs

```elixir
......
config :web_demo, :dns_cluster_query, System.get_env("DNS_CLUSTER_QUERY")

host = System.get_env("PHX_HOST") || "example.com"
port = String.to_integer(System.get_env("PORT", "4000"))

config :web_demo, WebDemoWeb.Endpoint,
  # 为 phoenix 的 url 辅助函数（如 ~p、url/3） 生成连接
  url: [host: host, port: port, scheme: "http"],
  http: [
    ip: {0, 0, 0, 0, 0, 0, 0, 0},
    port: port
  ],
  secret_key_base: secret_key_base
```
