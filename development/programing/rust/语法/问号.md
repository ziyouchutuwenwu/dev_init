# 问号

## 说明

处理 Option 和 Result 时，成功则取出值，如遇 None 或 Err，则提前退出，错误往上抛

## 例子

```rust
fn demo(num: &str) -> Result<i32, std::num::ParseIntError> {
    let n = num.parse::<i32>()?;
    Ok(n * 2)
}

fn main() {
    match demo("42") {
        Ok(v) => println!("结果: {}", v),
        Err(e) => println!("错误: {}", e),
    }

    match demo("abc") {
        Ok(v) => println!("结果: {}", v),
        Err(e) => println!("错误: {}", e),
    }
}
```
