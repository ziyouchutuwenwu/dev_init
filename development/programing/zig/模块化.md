# 模块化

## 例子

目录结构

```sh
src
├── main.zig
└── sub1
    ├── aaa.zig
    └── mod.zig
```

sub1/mod.zig

```zig
pub const aaa = @import("aaa.zig");
```

sub1/aaa.zig

```zig
const std = @import("std");

pub fn demo1() void {
    std.log.debug("demo1 {s} {s}", .{ "aaa", "bbb" });
}

pub fn demo2(a: u8, b: u8) u8 {
    return a + b;
}
```

main.zig

```zig
const std = @import("std");
const sub1 = @import("sub1/mod.zig");

pub fn main() void {
    sub1.aaa.demo1();

    const xx = sub1.aaa.demo2(11, 22);
    std.log.debug("demo2 result {d}", .{xx});
}
```

运行

```sh
zig build run
```
