# 构建

## 说明

自定义构建

## 例子

使用 musl, 无依赖

```zig
const target = b.standardTargetOptions(.{
    .default_target = .{
        // .cpu_arch = .x86_64,
        // .os_tag = .linux,
        .abi = .musl,
    },
});
```

指定 release 使用方式

```zig
const optimize = b.standardOptimizeOption(.{
   .preferred_optimize_mode = .small,
});
```
