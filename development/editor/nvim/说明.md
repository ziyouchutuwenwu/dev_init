# 说明

## 快捷键

一些常用的

```sh
alt+1    切换左侧文件浏览器 (Neo-tree)
alt+2    切换代码大纲 (Aerial)
alt+3    切换任务面板 (Overseer)
alt+4    运行任务模版 (Overseer)
ctrl+`   切换底部终端 (内置多终端管理)

ctrl+a   全选
ctrl+c   复制到系统剪贴板 (普通/可视模式)
ctrl+v   粘贴系统剪贴板 (平滑光标插入)
ctrl+x   剪切到系统剪贴板
ctrl+s   保存文件
ctrl+z   撤销
ctrl+y   重做

space+co 关闭其他文件

y/p/d    Vim 内部寄存器 (不污染系统剪贴板)
alt+.    forward (下一个位置)
alt+,    backword (上一个位置)
gd       转到定义
gr       转到引用
```
