# 说明

## 快捷键

一些常用的

```sh
Alt+1   切换左侧文件浏览器 (Neo-tree)
Alt+2   切换代码大纲 (Aerial)
Alt+3   切换任务面板 (Overseer)
Alt+4   运行任务模版 (Overseer)

Ctrl+a  全选
Ctrl+c  复制到系统剪贴板 (普通/可视模式)
Ctrl+v  粘贴系统剪贴板 (平滑光标插入)
Ctrl+x  剪切到系统剪贴板
Ctrl+s  保存文件
Ctrl+z  撤销
Ctrl+y  重做

y/p/d   Vim 内部寄存器 (不污染系统剪贴板)
M-.     forward (下一个位置)
M-,     backword (上一个位置)
gd      转到定义
gr      转到引用
alt+上下 移动当前行/选中行
```

## log

log 所在路径
